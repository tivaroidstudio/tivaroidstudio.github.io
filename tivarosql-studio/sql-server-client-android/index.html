SQL Server · Android

SQL Server client for Android

Query Microsoft SQL Server and Azure SQL from your phone: a native TDS driver, a T-SQL editor and a clean data grid – no remote desktop, no VPN app gymnastics.

▶ Get it on Google Play

Works with: Microsoft SQL Server (Standard, Enterprise, Express, Developer) and Azure SQL Database.

How to connect to SQL Server from Android

  1. Tap + New → SQL Server, or paste a jdbc:sqlserver://host;databaseName=… string.
  2. Enter host, port 1433, database, user and password. For Azure SQL keep encryption on.
  3. Use read-only mode for reporting accounts and tag production servers as PROD.
  4. Connect and run T-SQL; results appear in a sortable, filterable grid.

Private and safe by design

TivaroSQL Studio connects directly from your phone to SQL Server – there is no proxy server and no account. Passwords and keys are encrypted with Android Keystore, the app has no ads, analytics or tracking, and you can lock it or a single connection with your fingerprint.

Frequently asked questions

Does it need a VPN or a gateway?

No gateway. The phone connects directly to the server, so it must be reachable from your network – or use the SSH tunnel (Pro).

Can I connect to Azure SQL Database?

Yes, with SQL authentication over an encrypted connection.

Are my passwords safe?

Passwords are encrypted with Android Keystore and never leave the device.
