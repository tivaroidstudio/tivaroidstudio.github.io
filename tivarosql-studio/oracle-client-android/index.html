Oracle · Android

Oracle Database client for Android

Run SQL and PL/SQL against Oracle Database from your phone. The thin driver is built in – nothing to install, no Instant Client, no Java.

▶ Get it on Google Play

Works with: Oracle Database (including the free 23ai edition) and Oracle Autonomous Database, using a host, port and service name.

How to connect to Oracle from Android

  1. Tap + New → Oracle.
  2. Enter host, port 1521 and the service name (for example FREEPDB1), then user and password.
  3. Tag the connection and choose auto-commit or manual transactions with Commit / Rollback.
  4. Connect – unquoted names are upper-cased the Oracle way, so select * from employees just works.

Results to CSV and JSON, more formats in Pro.

Private and safe by design

TivaroSQL Studio connects directly from your phone to Oracle – there is no proxy server and no account. Passwords and keys are encrypted with Android Keystore, the app has no ads, analytics or tracking, and you can lock it or a single connection with your fingerprint.

Frequently asked questions

Do I need Oracle Instant Client?

No. The driver is built into the app.

Which identifier do I enter – SID or service name?

Use the service name, e.g. FREEPDB1 or ORCLPDB1.

Is Oracle support free?

Yes, all database engines are available in the free version.
