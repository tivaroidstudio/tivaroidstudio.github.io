Redis client for Android

Look into a cache, check a key or flush a stuck queue from your phone. Commands work like in redis-cli, and keys are grouped by type in the navigator.

▶ Get it on Google Play

Works with: Redis, Valkey, Redis Cloud and Upstash.

How to connect to Redis from Android

  1. Tap + New → Redis, or paste a redis:// / rediss:// URL.
  2. Enter host, port 6379, database number and password; enable TLS for Upstash or Redis Cloud.
  3. Connect – keys appear grouped by type (strings, hashes, lists, sets, sorted sets).
  4. Type one command per line, e.g. GET session:42 or HGETALL user:7.

Private and safe by design

TivaroSQL Studio connects directly from your phone to Redis – there is no proxy server and no account. Passwords and keys are encrypted with Android Keystore, the app has no ads, analytics or tracking, and you can lock it or a single connection with your fingerprint.

Frequently asked questions

Does it work with Upstash?

Yes – use the endpoint, port and password from the Upstash console with TLS enabled.

Can I use Valkey?

Yes, Valkey is Redis-compatible.

Can I accidentally FLUSHALL production?

Tag the connection PROD: every write command then asks for confirmation. Read-only mode blocks writes in the app.
